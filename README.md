## 🚀 Projetos em Destaque

### 📚 [EscolaWeb](https://github.com/andretti101/escolaweb)
> Sistema de gestão escolar completo com Java e Spring Boot

- Gerenciamento de alunos, professores, matrículas, aulas, frequência e notas
- Autenticação e autorização com **Spring Security + JWT**, acesso por perfil de usuário
- Persistência com **JPA/Hibernate + PostgreSQL**, versionamento de schema com **Flyway**
- API REST documentada com **Swagger**, testada com **Postman**

`Java` `Spring Boot` `Spring Security` `JWT` `PostgreSQL` `Flyway` `Swagger` `Docker`
